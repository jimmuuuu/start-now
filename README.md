# START/NOW Fitness MVP

A mobile-first beginner fitness web app built from the START/NOW concept.

## Included
- Home dashboard
- Push Day workout flow
- Exercise sets/reps logging
- Workout completion summary
- A–F workout grade with percentage
- Streak tracking
- Progress dashboard
- Achievements
- Profile
- Optional dark mode
- Local persistence using localStorage
- Installable PWA basics (manifest + service worker)

## Run
Open `index.html` in a browser.

For PWA/service-worker behavior, run it from a local web server, for example:
`python -m http.server 8000`

Then open:
`http://localhost:8000`
