Support

Use this page for the most common beta problems while START/NOW is being prepared for public release.

Workout data or cloud sync

If you are signed in, open Profile → Account and choose Sync now. If cloud sync temporarily fails, START/NOW continues saving a device copy and retries automatically.

The app looks outdated after an update

Refresh the page once. START/NOW includes build-version cache cleanup, so a normal reload should pull the current JavaScript and styles. During beta testing, a hard refresh can also help after a deployment.

A workout was interrupted

START/NOW saves active workout recovery data on the device. Reopen the app and return to the workout flow. If you are signed in, completed workout history is also backed up to your account.

Sign-in problems

Make sure you are using the same email address used to create the account. New accounts may require email confirmation before the first successful sign-in. Passwords must be at least 8 characters in the current beta.

Delete your account

Open Profile → Account → Delete account. The app asks for confirmation before permanently removing the account and associated cloud workout data.

Report a beta bug

For the current beta, report reproducible problems through the project's GitHub issue tracker. Include what screen you were on, what you tapped, what you expected, and what happened instead. Do not include passwords or other private account credentials.
